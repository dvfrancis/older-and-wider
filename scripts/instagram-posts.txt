# The posts on the message board page.
#
# Write one post on each line. Put the newest post at the top.
# Use this format:
#
#   date | address of the post | short text
#
# For example:
#
#   2026-11-27 | https://www.instagram.com/p/POSTID/ | A short summary in your own words
#
# Rules:
# - Write the date as year-month-day, for example 2026-11-27.
# - Copy the address of the post from Instagram. It starts with https://www.instagram.com/p/ or https://www.instagram.com/reel/.
# - You can paste a link from the Share button. The action removes the part after the ? character.
# - Write the short text in your own words. Do not use the | character in the text.
# - Put the text in double quotes to show it as a quote from the post.
# - The page shows a /p/ post as "Photo" and a /reel/ post as "Video".
# - To show a post as a set of photos, add a fourth part: | photo set
# - The page shows the 10 newest posts.
# - A line that starts with # is a note. The page does not show it.
#
# When you commit a change to this file on main, the update action builds the page.
# If a line is not correct, the action stops and names the line. The page does not change.
